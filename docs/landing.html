Como Usar

Do install ao build em 3 passos

Passo 1

Instalar o BBuilder

Instale globalmente via npm. Uma linha, pronto.

npm install -g @brunoluizdesiqueira/bbuilder-cli
📸
Captura: Instalação
📸
Captura: Config Init
Passo 2

Criar Configuração

Execute config init para criar o arquivo de configuração base.

bbuilder config init
Passo 3

Compilar Projeto

Execute bbuilder para modo interativo ou use atalhos como bbuilder fast.

bbuilder fast --project Bimer
📸
Captura: Build

Modos de Build

Escolha o modo ideal para cada situação

⚡

FAST

Compilação rápida, sem rebuild completo. Ideal para testes durante desenvolvimento.

Executa após compilar
🐛

DEBUG

Build completo com símbolos de debug. Use para investigar problemas.

Executa após compilar
🚀

RELEASE

Build otimizado para produção. Gera o executável final.

Não executa
